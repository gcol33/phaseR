# Moments of the one-step predictive distribution

Moments of the one-step predictive distribution

## Usage

``` r
one_step_moments(object)
```

## Arguments

- object:

  A `phase_fit` object

## Value

List with `mean` and `var` per row of the data: the predictive mean and
variance of y_t given y_0, ..., y\_(t-1), over the posterior
