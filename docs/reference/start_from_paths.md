# Parameter vector fitted to provisional phase paths

Parameter vector fitted to provisional phase paths

## Usage

``` r
start_from_paths(phase, target)
```

## Arguments

- phase:

  0-based phase of every observation, from
  [`phase_paths()`](https://gillescolling.com/phaseR/reference/phase_paths.md)

- target:

  Model description from
  [`posterior_target()`](https://gillescolling.com/phaseR/reference/posterior_target.md)

## Value

Parameter vector
